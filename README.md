# Odoo Dev Journey — رحلتي من Implementor إلى Full-Stack Developer

نظام شامل لإدارة التعلم وتتبع التقدم للانتقال من **Odoo Implementor** (صفر خبرة بايثون) إلى **Odoo 19 Full-Stack Developer** خلال 12 أسبوعاً بواقع ساعتين يومياً (120 ساعة مذاكرة أساسية).

---

## 1. المعمارية الفنية (Architecture Overview)

- **الواجهة الأمامية (Frontend):** React 19 + TypeScript + Vite.
- **التصميم وتجربة المستخدم (UI/UX):** Tailwind CSS v4، دعم كامل للغة العربية والاتجاه من اليمين لليسار (`dir="rtl"`).
- **الخطوط:** Cairo و JetBrains Mono.
- **الأيقونات:** Lucide React.
- **المخططات البيانية (Charts):** رسومات SVG مخصصة ومتجاوبة 100% بدون أي تعارض في التبعيات، مع دعم دقيق لاتجاه RTL (مقارنة الساعات الأسبوعية، إنجاز المهام الأساسية، والمخطط الراداري للمهارات).
- **المنطقة الزمنية:** `Africa/Cairo` بشكل صارم وموحد.

### هيكل البيانات والتخزين (Storage Architecture)
تم تصميم طبقة تخزين مجردة (`storageAdapter`) تضمن استقلالية منطق التطبيق عن وسيط التخزين:
1. **الوضع المحلي الأساسي (Local Mode):**
   - تخزين دائم عبر **IndexedDB** (`OdooDevJourneyDB`) مع مزامنة فورية في `localStorage` كشبكة أمان إضافية.
   - البيانات مستمرة وتبقى محفوظة عند تحديث الصفحة أو إغلاق المتصفح.
   - مؤشر مرئي واضح يبين حالة الحفظ ووقت آخر عملية تعديل.
   - دعم التصدير والاستيراد الكامل بصيغة **JSON**، مع التحقق الأمني من هيكل الملف قبل الاستعادة.
   - تصدير سجلات الأنشطة والجلسات بصيغة **CSV** مع معيار `UTF-8 BOM` لفتحها بشكل سليم في Microsoft Excel.
2. **الوضع السحابي (Cloud Mode):**
   - هيكل البيانات والواجهات مؤهلة للربط السحابي مع Firebase Auth و Cloud Firestore عبر معرّف المستخدم.
   - توفير مسار استيراد آمن لنقل السجلات المحلية إلى السحابة دون تكرار.

## 2. أقسام التطبيق العشرة (Main Navigation Views)

1. **لوحة التحكم (Dashboard):**
   - مؤشرات الإنجاز الحقيقية (نسبة إنجاز الخطة من أصل 60 مهمة أساسية، الساعات الفعلية المسجلة، الأيام النشطة، سلسلة الالتزام الحقيقية Streak، متوسط التقييمات المسجلة).
   - زر "استئناف التعلم" المباشر لفتح المهمة القادمة.
   - مخطط مقارنة الساعات المخططة (10س/أسبوع) بالساعات الفعلية.
   - مخطط إنجاز المهام الأساسية ومخطط راداري للمهارات التقنية الـ 15.
   - تنبيهات المهام المتوقفة أو العوائق.

2. **خطة الـ 12 أسبوع (Roadmap):**
   - استعراض المنهج الكامل (60 مهمة أساسية + 12 مراجعة أسبوعية اختيارية + أيام الراحة).
   - تصفية متقدمة حسب الأسبوع، الحالة (لم تبدأ، قيد التنفيذ، مكتملة، متوقفة)، والمهارة التقنية.
   - نافذة تفاصيل المهمة التفصيلية: الأهداف، التمارين، معايير القبول، الملاحظات الذاتية، ومقتطفات الكود.

3. **مهام اليوم (Today's Tasks):**
   - محطة عمل يومية تعرض مهام التاريخ المختار.
   - تقويم للتنقل بين الأيام السابقة والقادمة.
   - مؤقت المذاكرة التفاعلي، وتسجيل الأنشطة وتحديث الحالات بعد تأكيد المستخدم.

4. **سجل المذاكرة والأنشطة (Activity Journal):**
   - إدارة كاملة للعمليات (CRUD): إنشاء، قراءة، تعديل، حذف.
   - حقول التوثيق: المدة، نوع النشاط، الملخص، ما تم تعلمه، التحدي والحل، الكود، ومستوى الثقة.
   - تصدير فوري إلى ملف CSV.

5. **المشروعات العملية (Projects Portfolio):**
   - **مشروع أ:** موديول الأصول التدريبي (`training_asset`).
   - **مشروع ب:** توسعة تكاليف الشحن والتفريغ (`Landed Cost Extension`).
   - **مشروع ج:** لوحة المؤشرات المالية بـ OWL (`Financial Dashboard`).
   - **مشروع التخرج:** نظام إدارة الأصول المتقدم (`asset_management_plus`).
   - احتساب نسبة الإنجاز رياضياً من معالم الإنجاز والمخرجات المسلمة حصراً.

6. **المهارات والتقييمات (Skills & Assessments):**
   - مصفوفة المهارات التقنية الـ 15 (بايثون، OOP، Git، SQL، ORM، Views، Security، QWeb، Controllers، OWL، إلخ).
   - التقييم الذاتي من 1 إلى 5 مع إرفاق الأدلة البرمجية ونقاط التحسين.
   - سجل التقييمات التاريخي والمخطط الراداري.

7. **المراجعة الأسبوعية (Weekly Reviews):**
   - استمارة المراجعة والتأمل لكل أسبوع (ما تعلمته، ما بنيته، أصعب مشكلة وحلها، الأولويات القادمة).
   - مقارنة إحصائية رياضية بين الأسبوع الحالي والسابق.

8. **مكتبة المصادر (Resource Library):**
   - الروابط الرسمية المعتمدة لـ Python، Git، PostgreSQL، Odoo 19 Backend، HTTP، و Frontend OWL.
   - إمكانية إضافة وحذف مصادر مخصصة مع التصنيف والوسوم.

9. **التقارير والتحليلات (Reports & Analytics):**
   - تقارير إنجاز تفصيلية ومصفوفة جداول كاملة.
   - تصميم متجاوب مخصص للطباعة كـ PDF عبر أمر المتصفح (`Ctrl + P`).

10. **الإعدادات والنسخ الاحتياطي (Settings & Backup):**
    - تعديل تاريخ بدء الخطة والهدف اليومي والمظهر (ليلي/مضيء).
    - تصدير واستيراد النسخ الاحتياطية JSON مع التحقق الصارم من صحة الملف.
    - خيارات إعادة التعيين الآمنة مع تأكيدات الحماية.

## 3. طريقة التشغيل (How to Run)

```bash
# تثبيت التبعيات
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء النسخة الإنتاجية
npm run build

# فحص توافق الأنواع والشيفرة
npm run lint
```

## 4. قائمة الفحص اليدوي (Manual Testing Checklist)

- [x] **تخزين البيانات:** إنشاء نشاط، تحديث الصفحة، والتأكد من بقاء السجل وساعات المذاكرة.
- [x] **تحديث الخطة:** تغيير حالة مهمة إلى "مكتملة"، وملاحظة تحديث بطاقة الإنجاز في لوحة التحكم فوراً.
- [x] **مؤقت المذاكرة:** بدء المؤقت، إيقافه مؤقتاً، ثم إنهاؤه ونقل الدقائق المنقضية إلى استمارة النشاط.
- [x] **المشروعات:** تحديد مخرجات معينة في مشروع أ، والتأكد من ارتفاع نسبة الإنجاز المحسوبة تلقائياً.
- [x] **التقييم الذاتي للمهارات:** تقييم مهارة بايثون بمستوى 4 مع إرفاق الدليل وملاحظة تحديث المخطط الراداري.
- [x] **النسخ الاحتياطي:** تصدير ملف JSON، ثم استيراده والتحقق من سلامة البيانات المستعادة.
- [x] **تصدير CSV:** الضغط على زر تصدير CSV وفتح الملف للتأكد من دعم اللغة العربية والترميز.
- [x] **الطباعة:** فتح صفحة التقارير واستخدام زر الطباعة لمعاينة تصميم PDF الأنيق الخالي من عناصر التنقل.
- [x] **التجاوب والمظهر:** التبديل بين الوضع الليلي والوضع المضيء وفحص القائمة في الشاشات الصغيرة (Mobile Drawer).
